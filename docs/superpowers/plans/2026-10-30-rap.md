# Rap — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une PWA mobile d'écriture de rap qui range texte/brouillons/idées en placards repliables, surligne les rimes en couleur, aide à rimer et compte les pieds — en français, hors ligne.

**Architecture:** App d'une seule page en JavaScript natif (modules ES, aucun framework, aucun bundler), servie en statique (GitHub Pages). Logique pure (phonétique, rimes, syllabes, modèle, persistance) isolée dans des modules testés sous Node ; l'UI rend deux écrans (accueil, morceau) et branche cette logique. Les données vivent en IndexedDB ; un dico phonétique français compact est un asset statique committé, préparé une fois par un script dev et chargé en différé au runtime.

**Tech Stack:** HTML/CSS/JS natifs (ES modules), IndexedDB, service worker + web manifest, dictionnaire phonétique dérivé de Lexique 3.83. Tests : runner intégré `node --test` ; `fake-indexeddb` en devDependency pour le store.

**Spec:** `docs/superpowers/specs/2026-10-30-rap-design.md` (à lire avec ce plan).

## Global Constraints

- **Sans étape de build pour l'app** : le navigateur charge les fichiers tels quels. `tools/build-dico.mjs` est un script dev lancé à la main qui produit un asset committé ; ce n'est pas un build de l'app.
- **Hors ligne total** : aucun appel réseau au runtime hors chargement des assets du même origine.
- **Cible Android / Chrome**, mobile-first, utilisable à une main ; pas de framework, pas de CDN.
- **Français** : phonétique, rimes et syllabes doivent être justes en FR.
- **Stockage local seul** en v1 (IndexedDB) ; aucune synchro cloud, aucun compte.
- **Démarrage découplé** : app + capture d'idée instantanées ; dico phonétique chargé en différé.
- **Jamais jeté en silence** : un brouillon dont la ligne disparaît devient un « brouillon détaché » conservé ; toute suppression est une action explicite de l'utilisateur.
- **Attribution Lexique** : Lexique est sous licence CC-BY-SA 4.0 — une mention « Données : Lexique.org (CC-BY-SA) » figure dans l'écran « À propos ».
- **Node ≥ 18** (pour `node:test`).

## Review Focus

- **Mot hors-dico (argot, verlan, anglicisme)** : la phonétisation doit retomber sur les règles G2P et produire un résultat plausible sans planter. → test ajouté Task 2.
- **Vers vide ou finissant par ponctuation/chiffre** : surlignage de rime et compteur de pieds ne doivent ni planter ni colorer n'importe quoi. → test ajouté Task 5 et Task 3.
- **Normalisation (accents, apostrophe, casse, « l'or », « Noir »)** : le lookup phonétique doit retrouver le mot. → test ajouté Task 1.
- **IndexedDB indisponible ou plein (nav. privée, quota)** : l'app prévient et ne perd pas de données en silence. → test ajouté Task 8.
- **Texte long (beaucoup de lignes)** : le re-surlignage à la frappe reste incrémental (seule la ligne éditée est recalculée). → test ajouté Task 5.

### Task 4 : Richesse d'une rime

**Files:**
- Create: `js/rimes.js`
- Test: `test/rimes-richesse.test.mjs`

**Interfaces:**
- Consumes: `phonemiser` (Task 2).
- Produces: `classerRime(motA: string, motB: string): 'aucune'|'pauvre'|'suffisante'|'riche'` — compare les phonèmes de fin : 1 phonème commun final dont la voyelle = pauvre ; voyelle + 1 consonne (ou 2 phonèmes communs) = suffisante ; ≥ 3 phonèmes communs = riche ; 0 = aucune. Un mot identique à lui-même ≠ rime (rend 'aucune').

- [ ] **Step 1 : test qui échoue** — paires : noir/mémoire→suffisante ou riche (selon phonèmes communs, assertion exacte), mesure/armure→riche, chat/rat→pauvre, noir/table→aucune, mot/mot→aucune.
- [ ] **Step 2 : vérifier l'échec.**
- [ ] **Step 3 : implémenter `classerRime`** — comparer les suffixes phonémiques, longueur du suffixe commun → catégorie selon la règle ci-dessus.
- [ ] **Step 4 : vérifier le succès.**
- [ ] **Step 5 : commit.**

### Task 5 : Groupes de rimes d'un texte (surlignage)

**Interfaces:**
- Consumes: `phonemiser`, `classerRime`.
